# Fast NPC Helper

A lightweight Foundry VTT v13 module for PF2e, authored by Patchy, that adds a `Quick NPC` option to the actor directory context menu.

## What it does

- Adds `Quick NPC` when you right-click a PF2e NPC actor in the Actors tab.
- Opens a small builder window with:
  - level input,
  - role buttons for `Warrior`, `Archer`, `Mage`, and `Priest`,
  - boon and flaw checkboxes,
  - a live preview of the generated template.
- Applies a generated stat package to the selected NPC actor.
- Replaces only the embedded items previously generated by this module.

## Current first-pass scope

- Uses role-based level formulas for AC, HP, saves, perception, attacks, and skills.
- Generates strike items for every role.
- Generates spellcasting and SRD spells for `Mage` and `Priest` when the `pf2e.spells-srd` pack is available.
- Writes a generated notes block into the NPC's public notes so it can be refreshed cleanly.

## Install locally

Place this folder in your Foundry user data `Data/modules/` directory under the folder name:

`fastnpchelper`

Then enable the module in your PF2e world.

## Notes

This is intentionally a practical prototype rather than a full GMG creature-building rules engine. The formulas and spell packages are easy to tune in `scripts/fast-npc-helper-generator.js`.
